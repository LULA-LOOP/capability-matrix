How to read this

“Limited / scoped” means the action is restricted to the current account, assigned work, linked entities, or a subset of operations. “Cannot” means no corresponding protected v2 route was found. The Mobile App combines commuter, driver, and delivery account experiences; available actions depend on the signed-in account.

Authorization caveat

Command Centre capabilities vary by internal role. Several Command Centre controllers do not consistently enforce the permission matrix, so effective API access may be broader than the intended role definition.
